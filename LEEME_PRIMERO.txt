CAMPO DEI FIORI — TODO EL PROYECTO EN UNA CARPETA

1. Extrae el ZIP completo. Obtendrás una carpeta llamada Campo_dei_Fiori.
2. Abre esa carpeta en Visual Studio Code para revisar el código.
3. Para ver la página, abre index.html en un navegador o usa Live Server.

Si prefieres un servidor local con Python:
  - Abre una terminal dentro de esta carpeta.
  - Ejecuta: python3 -m http.server 8000
  - En Windows también puedes usar: py -m http.server 8000
  - Visita http://localhost:8000 en tu navegador.
  - Para detenerlo, pulsa Ctrl+C en la terminal.
