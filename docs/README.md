# Documentación de Campo dei Fiori

- **Campo_dei_Fiori_Avance_3.docx:** informe editable, 25 páginas, con Ruth y Robert como integrantes.
- **Campo_dei_Fiori_Avance_3.pdf:** versión del informe para lectura.
- **Campo_dei_Fiori_Presentacion.pptx:** diapositivas editables con notas para sustentar el proyecto.
- **Campo_dei_Fiori_Presentacion.pdf:** versión de las diapositivas para lectura.
- **evidencias/:** capturas de la aplicación y resultados reales de verificación en Chromium.

El proyecto es una demostración académica de una florería ficticia. El catálogo, carrito, recomendador, formularios y pedidos se ejecutan en el navegador; no hay ventas, pagos ni entregas reales.

Para ejecutar el sitio, consulta el [README principal](../README.md).

Si PowerPoint sustituye alguna tipografía, las cuatro fuentes originales y sus licencias están en [assets/fonts](../assets/fonts/). Instálalas en tu equipo para conservar el diseño al editar; el PDF mantiene la apariencia de la versión revisada.
